# qa-toolkit

Набор независимых инструментов для QA/инфраструктурных проверок ВМ и окружений.
Каждый инструмент — отдельная папка в `tools/` со своим README.

## Инструменты

| Инструмент | Описание |
| --- | --- |
| [`offline-fio`](tools/offline-fio/README.md) | Дисковые проверки ВМ без интернета: офлайн-ISO со статическим fio. Проверка тарифных IOPS, заполнение диска, точечные замеры латентности и полосы, контроль целостности данных. |

## Структура репозитория

```
qa-toolkit/
├── .github/workflows/    # CI-workflow'ы (у GitHub Actions видны только отсюда)
├── tools/
│   └── offline-fio/
└── README.md             # этот файл
```
