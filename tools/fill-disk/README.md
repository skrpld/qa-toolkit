# fill-disk

Создаёт заданное количество файлов заданного размера в указанной директории —
для тестового заполнения диска ВМ.

## Запуск

```
./fill_disk.sh -d /path/to/dir -n 100 -s 10M [-p prefix] [-r]
```

| Флаг | Обязателен | Смысл                                                                 |
| ---- | ---------- | ----------------------------------------------------------------------|
| `-d` | да         | директория (создаётся автоматически, если не существует)              |
| `-n` | да         | количество файлов                                                     |
| `-s` | да         | размер одного файла (`1K`, `10M`, `2G`, ...)                          |
| `-p` | нет        | префикс имени файла (по умолчанию `file`)                             |
| `-r` | нет        | заполнять случайными данными вместо нулей                             |

## Нюанс со sparse-файлами

Без `-r` файлы создаются через `fallocate` — мгновенно, но могут быть sparse:
если ФС/бэкап поддерживает дедупликацию или спарс-файлы, реальное место на
диске может не расходоваться. Для гарантированного расхода места используй `-r`
(медленнее — пишет `/dev/urandom`).
